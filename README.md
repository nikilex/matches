# Спички

Комнаты с игрой в реальном времени. Node.js 22+, WebSocket, без сборки клиентского приложения.

```sh
npm install
npm start
```

Открыть http://localhost:3000. Порт задаётся переменной `PORT`. Для игры с телефонами в одной сети открыть IP компьютера с портом 3000; для доступа из интернета разместить приложение на сервере с поддержкой WebSocket и HTTPS (прокси должен передавать Upgrade).

Игрок вводит имя, создаёт комнату на 2–20 человек или входит по коду/ссылке. Число коротких спичек — от 1 до числа игроков минус один. Ведущий тоже играет. Можно тянуть сразу после входа, не дожидаясь всей компании. Каждый выбирает одну спичку; результат виден всем. После всех выборов ведущий запускает новый раунд.

Имя и секретный ключ возвращения в комнату хранятся в localStorage браузера. При потере связи клиент переподключается и возвращается на своё место. Одна игровая сессия активна в одной вкладке. Закрытые вкладки сохраняют место для возвращения. Комнаты хранятся в памяти одного процесса: перезапуск сервера удаляет их, неактивные комнаты очищаются через сутки. Для нескольких серверных экземпляров потребуется общее хранилище и шина событий. Знание ссылки позволяет войти в свободное место комнаты.

`npm test` — интеграционные проверки HTTP и настоящих WebSocket-клиентов: скрытые результаты, конкурентный выбор, переподключение и новый раунд.
